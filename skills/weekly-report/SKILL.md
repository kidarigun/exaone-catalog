# 주간 업무 보고서

## 언제 쓰나요
- "주간 보고서 써 줘", "이번 주 업무 정리해 줘"처럼 한 주의 업무를 보고서로 만들 때
- 사용자가 업무 메모, 일정, 회의 내용 등을 주고 보고서로 정리해 달라고 할 때

## 작성 순서
1. 사용자가 준 내용에서 **완료한 일 / 진행 중인 일 / 다음 주 계획 / 이슈·요청 사항**을 골라냅니다.
2. 빠진 정보(보고 기간, 작성자, 부서)가 있으면 빈칸으로 두지 말고 `(입력 필요)`로 표시합니다.
3. 아래 형식으로 작성합니다. 문장은 "~함", "~예정" 같은 개조식으로 짧게 씁니다.
4. 수치(진척률, 건수, 금액)는 원문에 있는 것만 쓰고 지어내지 않습니다.

## 형식

```
# 주간 업무 보고 (YYYY.MM.DD ~ MM.DD)
작성: 이름 / 부서

## 1. 요약
- 핵심 성과 2~3줄

## 2. 이번 주 실적
| 업무 | 내용 | 진행 상태 |
|---|---|---|

## 3. 다음 주 계획
- 업무 — 목표 (마감일)

## 4. 이슈 및 요청 사항
- 이슈 — 영향 — 필요한 도움
```

## 파일로 원할 때
- 사용자가 Word 파일을 원하고 프로젝트 화면이라면 `보고서/주간보고_YYYYMMDD.docx` 경로로 write_file 하세요.
