# 업무 메일 쓰기

## 작성 원칙
1. **제목**: `[목적] 핵심 내용` 형식으로 25자 안팎 (예: `[요청] 3분기 매출 자료 공유 부탁드립니다`).
2. **인사**: 받는 사람 이름과 직함을 쓰고, 첫 연락이면 소속과 이름을 밝힙니다.
3. **본문 첫 문단에 용건**을 씁니다. 배경 설명은 그 다음에 짧게.
4. 상대가 할 일이 있으면 **무엇을, 언제까지** 해 주면 되는지 분명히 씁니다.
5. 날짜는 `11월 20일(목)`처럼 요일을 함께 씁니다.
6. 맺음말 뒤에 `이름 드림`으로 끝냅니다.

## 상황별 어조
- **요청**: "~해 주실 수 있을지 여쭙습니다", "~해 주시면 감사하겠습니다"
- **사과**: 변명보다 사실 인정 → 원인 → 조치 → 재발 방지 순서
- **독촉**: 탓하지 않고 일정을 다시 확인하는 표현 ("일정 확인차 다시 연락드립니다")
- **거절**: 감사 → 거절 이유 한 줄 → 대안 제시

## 출력 형식
```
제목: ...

본문
```
사용자가 어조(더 공손하게, 더 짧게)를 고치라고 하면 같은 내용으로 다시 씁니다. 두 가지 버전을 원하면 "버전 A / 버전 B"로 나눠 보여 줍니다.
